# template-sync

规则模板同步 Skill — 保持项目规则与全局规则同步。

## 触发条件

### 被动触发

当用户在对话中表达以下内容时，触发简短询问：

| 触发类型 | 触发词示例 |
|---------|-----------|
| 时间投入 | "花了 X 小时"、"搞了一整天"、"终于搞定了" |
| 踩坑经历 | "踩坑了"、"终于找到 bug"、"绕过了个坑" |
| 新工具引入 | "引入了 xxx"、"用了新工具" |
| 测试发现 | "测试发现"、"测试中注意到" |

**触发行为**：
```
用户：这个 bug 花了 2 小时才解决
AI：
> 检测到踩坑经历。记录到模板供其他项目参考？
> 1. ✅ 是
> 2. ⏰ 稍后
> 3. ❌ 跳过
```

### 主动检查

**触发时机**：每天首次进入项目对话时（项目 CLAUDE.md 存在）

**检查内容**：
1. 核心禁止规则是否存在（空壳函数、硬编码、错误处理等）
2. 测试策略章节是否完整
3. 触发机制章节是否存在
4. CHANGELOG 是否落后于模板

**差异级别**：
| 级别 | 定义 | 是否提醒 |
|------|------|---------|
| 关键差异 | 核心禁止规则缺失 | ✅ 主动提醒 |
| 建议差异 | 最佳实践章节缺失 | ⚠️ 静默，可手动查看 |
| 格式差异 | 标记/措辞不一致 | ℹ️ 不提醒 |

**检查行为**：
```
AI：
> [规则检查] 发现 1 处重要差异
> - ❌ "禁止空壳函数" 规则缺失
> 输入 "sync" 同步 / "detail" 详情 / "later" 稍后 / "ignore" 忽略此项目
```

## 功能

### 1. 被动记录（添加到模板）

当用户触发并选择"是"时：

1. 询问用户这条规则的类别：
   - 通用最佳实践
   - 规避的坑
   - 新工具/规范
   - 测试发现

2. 询问这条规则适用于：
   - 全局规则（所有项目）
   - 项目规则模板（未来新项目）
   - 当前项目

3. 执行更新，添加 CHANGELOG 条目

### 2. 主动检查（每天首次）

当检测到差异时：

1. 按优先级报告差异
2. 用户可选择：
   - `sync` — 同步
   - `detail` — 查看详情
   - `later` — 稍后提醒
   - `ignore` — 忽略此项目（添加标记）

### 3. 自动同步

当用户输入 `sync` 时：

```
AI：
> 正在同步...
> ✅ 更新：测试策略（使用模板版本）
> ✅ 更新：禁止行为章节
> ⏭️ 保留：项目特定规则
> ✅ 更新：CHANGELOG
> 
> 同步完成。备份已保存，如需回滚输入 "rollback"
```

**同步保护机制**：

| 章节 | 操作 |
|------|------|
| 测试策略 | ✅ 同步 |
| 禁止行为 | ✅ 同步 |
| 触发机制 | ✅ 同步 |
| 项目定位 | ⏭️ 保留 |
| 技术约束 | ⏭️ 保留 |
| 当前工作重点 | ⏭️ 保留 |

### 4. 回滚

当用户输入 `rollback` 时：

```
AI：
> 回滚到上一个版本...
> 已回滚。CLAUDE.md 已恢复。
```

### 5. 忽略项目

当用户输入 `ignore` 时：

```
AI：
> 将在此对话中忽略此项目的规则检查。
> 如需永久忽略，请在项目 CLAUDE.md 中添加：
> sync_disabled: true
```

## 快捷命令

| 命令 | 功能 |
|------|------|
| `sync` | 同步项目规则与模板 |
| `sync all` | 同步所有落后项目 |
| `detail` | 查看差异详情 |
| `later` | 稍后提醒 |
| `ignore` | 忽略此项目（本次对话） |
| `rollback` | 回滚上一次同步 |
| `check` | 手动触发规则检查 |

## 触发机制（原始定义）

当你在项目中做出以下行为时，思考是否需要同步更新模板：

**触发条件（满足任一即触发）**：
1. 发现了新的通用最佳实践
2. 规避了某个常见的坑
3. 引入了新的工具或规范
4. 花费超过 2 小时解决一个问题
5. 测试中发现的新坑

**判断标准**：
- 这个规则/坑能跨项目复用吗？
- 这个规则属于"通用底线"还是"项目特定"？
- 其他项目可能重蹈这个坑吗？

**3 个问题有 2 个"是" → 同步更新模板**

---

## 注意事项

1. **新项目保护**：初始化 < 7 天的项目，检查结果只报告不主动同步
2. **项目特定内容**：同步时保留项目独有的章节（定位、技术约束、工作重点）
3. **跨项目同步**：模板更新后，可选择同步到其他已有项目
